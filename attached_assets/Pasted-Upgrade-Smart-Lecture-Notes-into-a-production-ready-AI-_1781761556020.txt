### YouTube Processing

* App only shows preview.
* Start Processing remains disabled.

Required behavior:

1. Accept:

   * youtube.com URLs
   * youtu.be URLs
   * YouTube Shorts URLs

2. After URL validation:

   * Fetch title
   * Fetch thumbnail
   * Fetch duration
   * Fetch channel name

3. Enable Start Processing automatically.

4. If browser CORS restrictions prevent frame extraction:

   * Move video acquisition to backend.
   * Download/process video server-side.
   * Extract frames using FFmpeg.
   * Continue existing OCR pipeline.

5. Show errors for:

   * Invalid URL
   * Private video
   * Age-restricted video
   * Download failure
